# Azure更新情報

本リポジトリは筆者がAzureの更新情報を追い続けるためにWeekly UpdateやMicrosoft Igniteを視聴したメモから作成したレポートを保管するリポジトリである。

## フォルダ構成
フォルダとファイルの命名は以下とする
<作成日>_<レポート題名>.md
Microsoft Ignite関連は1開催1フォルダにまとめる。

## レポート形式
本リポジトリでは、筆者がセッションを視聴したメモからAIによる補足情報を追記し整理したものをレポートと定義する。

## AIエージェントへ
メモからレポートを作成する際は、必ず公式情報を調査し情報の正確性を確保すること。
また、レポートは要点を理解できるように簡潔に作成すること。
